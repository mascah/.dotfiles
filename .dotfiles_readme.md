# dotfiles

## Quick setup on a fresh Mac

After installing Xcode Command Line Tools and getting an SSH key onto the
machine (added to GitHub), the bootstrap script handles the rest:

```
git clone --bare git@github.com:mascah/.dotfiles.git $HOME/.dotfiles
/usr/bin/git --git-dir=$HOME/.dotfiles/ --work-tree=$HOME config --local status.showUntrackedFiles no
/usr/bin/git --git-dir=$HOME/.dotfiles/ --work-tree=$HOME checkout
chmod +x ~/.dotfiles_bootstrap.sh
~/.dotfiles_bootstrap.sh            # work machine
~/.dotfiles_bootstrap.sh --personal # personal machine: also .brewfile.personal
```

The bootstrap is idempotent — installs Homebrew, runs `.brewfile` (and
`.brewfile.personal` with `--personal`), installs oh-my-zsh (without clobbering
`.zshrc`), and runs `vim +PlugInstall`. Re-run any time to converge.

### Git identity per machine

`.gitconfig` holds only shared settings and refuses to commit until an email is
set (`useConfigOnly`). Each machine sets its own in the untracked
`~/.gitconfig.local`:

```
# personal machine
[user]
	email = <personal email>

# work machine: work email by default, personal email for personal repos
[user]
	email = <work email>
[includeIf "gitdir:~/GitHub/mascah/"]
	path = ~/.gitconfig.personal
```

where `~/.gitconfig.personal` (also untracked) sets the personal `[user] email`.

## Creating a dotfiles repo

1. `git init --bare $HOME/.dotfiles`
2. `alias config='/usr/bin/git --git-dir=$HOME/.dotfiles/ --work-tree=$HOME'`
3. `echo "alias config='/usr/bin/git --git-dir=$HOME/.dotfiles/ --work-tree=$HOME'" >> $HOME/.zsh/aliases`
4. `config config --local status.showUntrackedFiles no`
5. config add .vimrc + config commit -m "add .vimrc" + set up a remote repository on GitHub or your Git server of choice + config push

## Checking out dotfiles repo

1. `echo ".dotfiles" >> .gitignore`
2. `git clone --bare <remote-git-repo-url> $HOME/.dotfiles`
3. `alias config='/usr/bin/git --git-dir=$HOME/.dotfiles/ --work-tree=$HOME'`
4. `config config --local status.showUntrackedFiles no`
5. `config checkout`

```
echo ".dotfiles" >> .gitignore
git clone --bare <remote-git-repo-url> $HOME/.dotfiles
alias config='/usr/bin/git --git-dir=$HOME/.dotfiles/ --work-tree=$HOME'
config config --local status.showUntrackedFiles no
config checkout
```

## Installing

### Install 1password and login to account
[turn on the 1password cli integration](https://developer.1password.com/docs/cli/get-started/#step-2-turn-on-the-1password-desktop-app-integration)

### Install brew and install bundle

```
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

brew bundle --file=~/.brewfile
brew bundle --file=~/.brewfile.personal  # personal machines only
```

### Add id_ed25519 keys to .ssh dir

```
op read op://Personal/id_ed25519/notesPlain > ~/.ssh/id_ed25519
op read op://Personal/id_ed25519.pub/notesPlain > ~/.ssh/id_ed25519.pub

chmod 600 ~/.ssh/id_ed25519
```

### Install oh-my-zsh
```
sh -c "$(curl -fsSL https://raw.githubusercontent.com/ohmyzsh/ohmyzsh/master/tools/install.sh)"

mv ~/.zshrc ~/.zshrc.omz_generated
mv ~/.zshrc.pre-oh-my-zsh ~/.zshrc
```
